# 尽调报告逐章写作规则

## 一、报告的定位

报告是面向委托人的法律分析文件。它应说明已经查明的事实、这些事实反映的法律和交易风险，以及委托人可采取的措施。报告不是底稿摘要、缺件清单或工作过程记录。

除非律师明确要求，一次只撰写或深度修改一个报告章节。报告章节只能基于已经完成并经律师审阅的相关底稿和材料撰写。

撰写阶段使用 Markdown，逐章顺序续写，不改动已写好的前文；发现前文问题在对话中报告，由律师决定。整稿完成、律师指令后，按 [docx-format.md](docx-format.md) 转换为 DOCX。

## 二、报告骨架

首次创建报告文件时，先建立完整骨架，此后各轮在骨架内逐章填充。骨架按参考终稿的通行体例：

1. 目录（占位，成稿转换时生成）；
2. 报告标题与致送语（“致：[委托人全称]”）；
3. 定义与写作约定区（与底稿一致，转换 DOCX 时删除或并入释义）；
4. 声明与限定条件，通常含：出具依据、调查范围、调查方法、限制条件、项目概况摘要；
5. 各章空标题（默认“一、……”至“九、……”按项目实际设置）；
6. 末章“结论与风险提示”；
7. 落款（律师事务所、经办律师、报告日期）。

“声明与限定条件”是全报告统一限定的唯一位置，各章不再重复长篇免责。骨架建立后，其内容也遵守顺序续写纪律，非经律师指令不回改。

## 二之一、声明与限定条件的统一限定

各章不再分别作出调查限制的说明，全部限定集中在“声明与限定条件”中。未有律师格式蓝本时，“限制条件”部分可参照以下表述（按项目调整）：

> 1. 本报告所依据的资料截至[基准日]（下称“基准日”），本报告所发表的法律意见仅以基准日前取得的资料为基础。
> 2. 本报告以标的公司及相关方提供的文件资料、所作说明，以及本所律师通过公开渠道查询取得的信息为基础。本所律师假定：标的公司及相关方提供的文件资料真实、准确、完整，复印件与原件一致，文件上的签字和印章真实有效，所作说明不存在虚假记载、误导性陈述或重大遗漏。
> 3. 本报告所述“未发现”，系指在前述资料和公开查询范围内未发现，并非对相关事实不存在的保证。
> 4. 本报告不对会计、审计、资产评估、税务筹划、技术等非法律专业事项发表意见；本报告引用的该等数据和结论，均系对有关机构出具文件的引述。

律师在既往项目中已经确定格式蓝本或限定条款的，以律师的版本为准。

## 三、默认章节结构

每章通常采用：

1. 调查范围；
2. 基本情况；
3. 律师意见。

对应“（一）（二）（三）”三级小标题；基本情况之下按实质问题设“1. 2. 3.”小标题。律师意见可以分点，但每一点应是完整的法律分析，不采用“风险事项/等级/事实依据/法律依据/建议”的大表格。

“调查范围”小节只说明本章核查了哪些事项、依据了哪类材料和公开渠道，不写“未取得……”“未能获得……”等内容。

## 四、底稿到报告的转换

| 底稿内容 | 报告处理 |
|---|---|
| 核查范围与项目问题 | 压缩为与本章相关的调查范围，不写内部工作方法细节 |
| 核查材料 | 不在正文逐项列示；确有需要时汇总到报告附件 |
| 核查事实与分析 | 提炼为“基本情况”，保留支持判断的主体、日期、金额、期限、关键条款和勾稽关系；底稿中“尚不能确认……”“现有材料不能证明……”等句子按第五节改写或删除，不得保留 |
| 初步结论与风险 | 经复核后写入“律师意见”，补足法律依据、交易影响和可执行建议 |
| 待律师决定事项 | 不进入报告；由律师作出决定后反映最终口径 |
| 建议补充资料 | 不进入报告；补件需求由律师另行向标的公司提出 |
| 内部批注、流程状态、置信度、材料批次 | 全部删除 |
| 历史沿革 | 按 [history-records.md](history-records.md) 分段完整列举，不使用表格，不作概述 |
| 底稿中的核查限制和疑点 | 按第五节逐项确定去向，并在交付时向律师说明 |

## 五、报告是确定性陈述：调查限制不进入正文

报告向委托人陈述截至基准日已经查明的现状、风险和对策。报告正文中出现“现有材料不能证明……”“无法确认……”“标的公司未提供……”，委托人自然会追问：既然不能证明，为什么不要求标的公司补充？这类句子让报告看起来像一份尚未完成的调查记录。补件是底稿阶段由律师处理的事项，不是报告的内容。

### 1. 默认规则

报告正文（包括调查范围、基本情况、律师意见、结论与风险提示）不得出现描述调查限制或材料缺口的表述，包括但不限于：

- 现有材料（资料）不能证明、未能证明、不足以证明；
- 无法确认、尚不能确认、不能确认、无法核实、未能核实、无法判断、有待进一步核实、需进一步核查；
- 未提供、未包含、未取得、未见、资料中未体现、现有资料无……；
- 不能排除、无法排除；
- 建议补充提供……以便核实（核查）。

唯一的统一出口是“声明与限定条件”中的概括性限定（写法见第二节之一）。律师明确指示就某一具体事项向委托人披露调查限制的，按律师确定的口径书写，并在交付说明中注明。

### 2. 底稿中的每一条限制或疑点，在报告中只有四种去向

逐条判断，选择其一：

1. **删除**：与本章判断无关的材料库存、通用清单项目、印章清单和制度文件等“还可以有”的证明材料。报告只写已有的事实。
2. **改写为已查明的事实**：只写材料实际载明的内容，并注明来源；材料本身反映的问题（如实收资本低于注册资本、许可证即将到期、合同已过期）直接作为事实和风险陈述。
3. **改写为交易保护或整改措施**：底稿中尚未查清、但对项目有影响的事项，在律师意见中写为面向标的公司或交易安排的措施，例如将某事项列为签约或交割的前提条件、由标的公司及其股东作出陈述与保证并承担赔偿责任、设置价款调整或分期支付、要求限期办理或整改并提交证明文件。措施的主语是标的公司、交易各方或交易文件，不是“本所律师需进一步核查”。
4. **交由律师决定**：限制涉及重大事项，用上述三种方式都无法妥当处理时，不写入报告，在交付说明中提出，由律师决定口径。

### 3. 改写对照（虚构示例）

| 底稿表述 | 报告写法 | 去向 |
|---|---|---|
| 该记录显示公司设立时备案五枚印章。现有资料未包含迁址后的现行印章清单、最新备案查询结果、银行预留印鉴及印章管理制度。 | 根据标的公司提供的《印章备案记录》，标的公司于设立时备案法定名称章、合同专用章、财务专用章、发票专用章及法定代表人名章共五枚印章，备案时登记的单位地址为[地址]。 | 删除缺件部分 |
| 现有材料不能证明股东张某已缴足其认缴的出资。 | 根据[会计师事务所]出具的《审计报告》（[文号]），截至2025年12月31日，标的公司实收资本为人民币300万元，注册资本为人民币1,000万元，尚有人民币700万元未实缴。按照章程，张某认缴的出资应于[日期]前缴足。……建议在交易文件中约定，张某应在[时点]前缴足其认缴出资并提供银行入账凭证，作为[交割／付款]的前提条件。 | 改写为事实和措施 |
| 现有资料无法排除标的公司存在未披露的债务和对外担保。 | 在律师意见或结论中写：建议在交易文件中由标的公司及其股东就不存在未披露的债务、对外担保和或有负债作出陈述与保证，并约定违反陈述与保证时的赔偿责任。各章不重复。 | 改写为措施，集中一处 |
| 仅有公司说明，无其他材料佐证，无法核实员工无劳动争议。 | 根据标的公司出具的《说明》，截至基准日标的公司不存在劳动争议；经查询[平台]（查询日期：[日期]），未发现以标的公司为当事人的劳动争议裁判文书。 | 改写为事实，写明来源 |
| 未取得商标注册证。公开查询显示标的公司持有三项注册商标。 | 经查询[平台]（查询日期：[日期]），标的公司持有以下注册商标：……。 | 改写为事实，写明来源 |

### 4. 允许保留的来源性表述

以下表述说明事实来源，不属于调查限制，可以使用：

- “根据标的公司提供的《……》”“根据标的公司出具的《说明》”；
- “经查询[平台]（查询日期：[日期]），未发现……公开记录”；
- “截至基准日”“截至本报告出具日”。

否定性结论写为“根据标的公司提供的资料及[平台]查询结果，未发现标的公司存在……”，不写“现有资料未显示……”。

### 5. 不得错误推定

删除缺件表述不等于可以断言相反事实。不得把“未提供”写成“不存在”，也不得把公开查询无记录写成对事实不存在的保证。只写已有材料支持的内容。

底稿中确有一项限制属于重大事项，而删除、改写为事实和改写为交易措施都不足以处理时，不要自行断言，也不要写回调查限制式表述：不写入报告，在交付说明中列明并由律师决定口径；经律师决定后在“声明与限定条件”中作统一限定。

## 六、事实段的写法

一个完整的事实段通常包含以下内容中的必要部分：

- 文件或信息来源；
- 文件主体、日期和效力状态；
- 与本项目有关的关键条款、金额、比例、期限或登记事项；
- 与其他材料的核对结果；
- 该事实为后续法律意见提供的基础。

示例：

> 根据标的公司提供的现行章程及最新变更登记文件，标的公司的注册资本为人民币[金额]元，股东为[股东]，各股东应于[日期]前完成认缴出资。章程所载股东、出资额和持股比例与公开登记信息一致。

这比“标的公司已提供章程，股权结构详见下表”更便于客户理解和律师复核。（示例中的“标的公司”按项目“定义与写作约定区”选定的称谓替换。）

## 七、律师意见的写法

每项意见应完成一条可追踪的推理链：

`已查明事实 → 适用规则或交易要求 → 判断 → 对项目的影响 → 建议`

并非每项意见都需要逐字写出五个部分，但不得只有抽象结论或模板式提醒。

建议应具体说明责任主体、实施时点和措施。根据项目类型和风险性质选择先决条件、陈述与保证、承诺、赔偿、担保、价款调整、治理安排、资产合同或人员承接、整改要求、交割后措施或持续监督等适用工具，不要对所有问题统一写“建议补充资料并持续关注”。

建议是交易或整改措施，不是调查步骤。“建议委托人要求标的公司补充提供……以便进一步核实”不属于建议；应改写为第五节第 2 小节第 3 种去向中的交易保护或整改措施。

## 八、表格规则

报告中的表格比底稿更应克制。通常可使用表格的内容：

- 公司现行基本登记信息；
- 现行股权结构；
- 大量同类知识产权或重大合同；
- 多期财务数据。

律师意见、法律论证、风险后果和处理建议使用段落。一个章节如果已有信息表，后续分析尽量用文字展开。不要用表格承担版面设计功能。

历史沿革（公司登记事项、股权、董事监事高级管理人员的历次变更）一律按 [history-records.md](history-records.md) 分段书写，不使用表格。

## 九、限定性表述

必要的限定应准确、集中、与具体结论相称。保留法律文本需要的“截至基准日”“根据标的公司提供的材料”“经查询未发现”等表述，但不要把同一限制在每段重复。

公开查询无记录时，报告可以写明查询平台和日期，并在相关结论确实依赖该查询时作一次适当限定。不得用冗长免责声明冲淡已有事实和真正风险。

## 十、结论章节

结论应回应项目目的，而不是把十章各压缩成一句套话。优先汇总：

- 是否存在阻碍项目目的实现的事项；
- 哪些风险需要在签约、交割、实施、整改或持续经营等本项目适用阶段处理；
- 哪些条件或措施应写入交易文件、项目文件或整改方案；
- 哪些事项需要持续监督。

结论不得新增底稿和正文没有分析过的事实或风险。

项目已经出具“重大问题清单及分级解决方案”的，结论章节对各问题的定性、分级和处理措施应与清单一致；存在差异的，在交付说明中向律师报告，由律师决定修改哪一份文件。
