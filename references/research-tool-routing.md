# 企业信息与司法案例检索路由

## 一、定位

本文件只负责在需要外部调查时选择数据获取工具。是否检索、如何使用结果、证据强度、报告表述和文件留存仍按 [public-information.md](public-information.md) 及主技能规则执行。

工具不可用、凭证缺失或存在更权威的官方来源时，可以使用环境内其他合适工具或公开来源，不把尽调工作绑定于单一平台。

## 二、企业信息调查

查询标的公司或其他相关主体自身的登记、股东、变更、知识产权、对外投资、担保、股权出质或冻结、经营异常、行政处罚、欠税、执行、失信、涉诉文书、法院公告和开庭公告等公开状态时：

1. 环境中存在 `yd-enterprise-info` 时，先读取该技能的 `SKILL.md`，再按本章实际问题调用最少必要的接口；
2. 不因接口可用而批量拉取全部数据，也不把其十章映射当作本项目的固定调查范围；
3. 工具不可用或查询事项有更适合的官方来源时，改用其他企业信息工具、登记机关或监管机关公开来源；
4. 查询标的公司自身的涉诉、执行和公告属于主体背景调查，仍适用本节。

## 三、司法案例检索

围绕法律争议焦点查找类案、典型案例、权威案例，或者需要核验案例详情时：

1. 环境中存在 `yd-case-search` 时，先读取该技能的 `SKILL.md`，再根据问题采用关键词检索或语义检索；
2. 先根据标题、法院、案由、裁判日期和摘要筛选相关结果，只对拟引用或确需核验的少量案例拉取详情；
3. 工具不可用或已有更权威来源时，改用人民法院、检察机关或其他可用法律数据库；
4. 检索相似争议的裁判尺度属于案例研究，不与企业信息工具中的标的公司涉诉查询混用。

## 四、与尽调工作流的衔接

- 外部工具只提供数据或检索结果，不替代律师对原始材料、事实可比性和法律意义的判断。
- 不自动创建 `raw/` 目录、接口日志、查询摘要或材料台账；只有律师要求留痕或工具运行必须落盘时，才按明确范围保存。
- 不因外部数据与公司材料冲突而自动确定风险等级。先分别记录来源和日期，分析冲突影响，再由律师决定是否补件、扩大核查或调整结论。
- 查询无记录只能表述为在特定来源和查询日期“未发现相关公开记录”，不得据此证明相关事实绝对不存在。
- 遵守被调用技能的凭证、费用和查询限制；需要消耗积分或产生其他成本时，不绕过相应确认要求。
